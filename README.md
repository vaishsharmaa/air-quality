# Air Quality Analysis Dashboard

Analyzing how air quality changes over time in Indian cities using Python, Pandas, Matplotlib and Streamlit.

## Dataset
- Air Quality Data in India (2015-2020), from Kaggle (by Rohan Rao)
- Originally published by the Central Pollution Control Board (CPCB), India
- File used: city_day.csv (daily data for 26 cities)

## Features (planned)
- AQI over time for a selected city
- Comparison of pollution levels across cities
- PM2.5 and PM10 charts
- Detection of unusually high pollution days
- Daily, weekly and seasonal patterns
- Interactive Streamlit dashboard

## Tools
Python, Pandas, Matplotlib, Streamlit
